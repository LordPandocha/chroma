# CHROMA

Статический сайт-визитка для веб-студии. Откройте `index.html` в браузере, чтобы посмотреть сайт локально. Для веб-хостинга загрузите содержимое этой папки в корень сайта. Сборка и установка зависимостей не нужны.

Основная кнопка открывает профиль [@LordPandocha](https://t.me/LordPandocha) в Telegram. Посетитель сам отправляет сообщение в приложении. В коде сайта нет форм, аналитических скриптов, cookies и внешних запросов при загрузке страницы. У хостинга могут быть собственные журналы доступа.

## Исходники

- `index.html` — содержание, навигация и контактные ссылки.
- `style.css` — адаптивная вёрстка и оформление.
- `app.js` — плавное свечение и параллакс от курсора. Эффект отключён на тачскринах и при включённом системном уменьшении движения.
- `assets/` — изображения, сгенерированные для сайта, и знак CHROMA. Контурные иконки основаны на [Lucide](https://lucide.dev/license).

Фотографии на Unsplash использовались как визуальные референсы. [Архитектурные линии](https://unsplash.com/photos/geometric-concrete-structure-with-glass-windows-Z3MsCdxNJg4/) · [Монохромный фасад](https://unsplash.com/photos/black-and-white-concrete-building-QxeGirsqcBw)

Для хранения исходников подойдёт репозиторий GitHub. При выборе хостинга для коммерческой витрины проверьте [ограничения GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits).
