# CHROMA — обновлённая версия

Статический сайт. Откройте index.html или запустите python -m http.server 4173.

Цены задаются в pricing.js: состав 5 900–21 900 ₽, материалы 0 / 500 / 1 500 ₽, срочность 0 / 700 / 1 600 ₽. Максимум 25 000 ₽. Сумма появляется после четырёх шагов. Итог ориентировочный, дополнительные интеграции обсуждаются отдельно.

app.js управляет темами, квизом и декоративными эффектами. style.css содержит явные палитры, адаптивную вёрстку и reduced-motion. assets содержит отдельные светлые и тёмные изображения WebP, включая мобильные версии. Генерация выполнена встроенным imagegen.

Серверной части и базы данных нет. Кнопка Telegram открывает черновик, пользователь отправляет его самостоятельно. Куки и аналитика не добавлены. В localStorage сохраняется только тема.
